# Build Heritage

Source for **buildheritage.org**, a static lead-generation site for a Georgia home-services company covering eight trades.

[![Live demo](https://img.shields.io/badge/live-demo-0E6B52)](https://buildheritage.org/) [![Stars](https://img.shields.io/github/stars/suncal/buildheritage?style=social)](https://github.com/suncal/buildheritage/stargazers)

![screenshot](docs/hero.png)

**Try it: https://buildheritage.org/**

## What it does

- Pure static HTML/CSS, hosted free on GitHub Pages
- One page per trade plus a contact flow

## Run it

Open `index.html`.
